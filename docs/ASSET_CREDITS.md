# EIDOLON — Asset Credits & Licensing

## Summary

Everything that appears on screen so far is generated by code in this
repository. No third-party images, models, textures, fonts or audio are included
in the repository or in the rendered frames.

|---|---|---|

## Reference images (not redistributed)

Seven images in a local `references/` folder guide the art direction. They are
third-party artworks collected from social media / image boards. **Their authors
and licences have not been verified**, so:

- the folder is listed in `.gitignore` and is not committed;
- no reference image is loaded, sampled, traced or displayed by the film;
- they are used only the way a mood board is used — to derive palette, lighting
  and composition principles, written up in [ART_DIRECTION.md](ART_DIRECTION.md).

If you are the author of one of these works, or can identify one, please open an
issue so that proper credit can be added (or the reference dropped).

Because the references are someone else's art, the film aims to work in their
visual *language* with original compositions. It does not reproduce specific
characters, signage, logos, text or real people's likenesses from them.
